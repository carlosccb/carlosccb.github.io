#### Machine Learning Regression and Classification Methods for Fog Events Prediction: A Performance-based Study

This paper is still in the manuscript phase, so it's work in progress, but all the experiments and results are done.
Here's an abridged version of the paper.

The data comes from the visibility on a highway in northern Spain measured with a laser device. Other variables are included. Fog gets so bad on this specific road that many time across the year it has to be closed, so the purpouse is to predict with ambiental variables what the visibility will be in the next [...] period of time.

For this task two main approaches can be taken, namely:
1. Predict the numerical value of visibility in meters
2. Predict the level of visibility according to [...]

In a machine learning context, 1 is a regression problem and 2 is a classification problem. Furthermore, 2 can be also treated as a ordinal classification problem.
